    HOW Why this works
    
    
    
      01
      
    
        
    Stored in visual order
    
        
    Urdu reads right-to-left; the game draws left-to-right. The converted name is stored in the
          order it should be seen, so the game draws it correctly without knowing any Urdu.
    
      
    
    
    
    
    
      02
      
    
        
    Real joining forms, per letter
    
        
    Every Arabic-script letter has up to four shapes. Photoshop-style exports use the lone shape
          for all of them — that's the split, broken look. Here each letter is given the initial, medial
          or final shape its position in the word actually requires.
    
      
    
    
    
    
    
      03
      
    
        
    Some gaps are correct Urdu
    
        
    Letters like alif and zay never join to the letter after them. A gap after one of those is not
          a bug — it's how the word is written. Everything that should join, joins.
