    1 · Reversed for the game

    Urdu is read right-to-left, Free Fire draws left-to-right. The output is stored in visual order, so the game draws it the way you read it.

    🔗

    2 · Real joining forms

    Photoshop-style exports give every letter its lone form — that's the broken, split-letter look. Here each letter gets its true initial, medial or final shape, so words actually join.

    ✈️

    3 · Some gaps are correct

    Letters like alif and zay never join to the letter after them. A gap after one of those is real Urdu, not a bug — everything that should join, joins.
